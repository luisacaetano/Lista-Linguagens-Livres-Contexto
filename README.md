# Lista - Linguagens Livres de Contexto

Exercícios sobre Linguagens Livres de Contexto e Autômatos de Pilha, desenvolvidos para a disciplina de Linguagens Formais e Autômatos.

## Conteúdo

Os exercícios abordam:

- Gramáticas Livres de Contexto (GLC)
- Autômatos de Pilha (PDA)
- Derivações e árvores sintáticas
- Forma Normal de Chomsky
- Lema do Bombeamento

## Estrutura

- `Exercicio*.jff` - Autômatos criados no JFLAP
- `Exercicio*.txt` - Resoluções em texto
- `Exercicio*.jpg` - Diagramas dos autômatos
- `Lista Completa.pdf` - Enunciados dos exercícios

## Ferramenta

Os autômatos foram desenvolvidos utilizando [JFLAP](http://www.jflap.org/) - Java Formal Languages and Automata Package.

## Como Abrir

1. Baixe e instale o JFLAP
2. Abra os arquivos `.jff` no programa
3. Simule as entradas para testar os autômatos
